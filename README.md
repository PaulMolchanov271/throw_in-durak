# Throw-In Durak

Сетевая карточная игра: сервер на C и графический клиент на C++/FLTK.
Поддерживается Linux; в Windows можно запускать через WSL с графической средой (WSLg).

## Сборка и запуск

Ubuntu / Debian:

```sh
sudo apt-get install build-essential libfltk1.3-dev libpng-dev python3
make
./server
```

В другом терминале из корня проекта:

```sh
./throw_in_durak
```

Запустите несколько клиентов для игры. Адрес сервера в клиенте — `127.0.0.1`, порт — `5555`.
Изображения карт загружаются из `ui/PNG-cards-1.3`, поэтому запускайте клиент из корня проекта.
Текстовый клиент: `make client_c && ./client_c`.

## Игра и новые возможности

- Войдите в аккаунт, зарегистрируйтесь или выберите гостевой вход.
- Создайте лобби или присоединитесь через **List of games**. Имя лобби — до 49 символов без пробелов. Галочка **Require password** включает пароль (1–64 байта UTF-8); при входе в защищённое лобби появится запрос пароля. Неверный пароль не даёт войти; ввод можно повторить или отменить.
- Хозяин лобби (первый игрок) нажимает **Start**, когда присутствуют минимум два игрока. Максимум — восемь.
- Нажатие на карту выделяет её для **Attack** / **Defend**. Можно также перетащить карту на стол; для защиты — на атакующую карту. Кнопка **Defend** отбивает первую неотбитую карту выбранной картой.
- **Правило этого проекта:** партия немедленно заканчивается, когда игрок легальным ходом избавился от последней карты, даже если в колоде ещё есть карты. Этот игрок получает победу, все остальные — поражение.
- Слева отображаются изображение козырной карты и **Deck: N cards** — число оставшихся карт, включая нижнюю козырную, пока она в колоде. Счётчик обновляется после добора.
- После завершения показывается результат, игровые действия отключаются. Хозяин может нажать **Restart**: колода, руки и стол создаются заново, участники и чат сохраняются.
- **Leave lobby** или закрытие игрового окна возвращает в главное меню. Выход или обрыв соединения во время партии считается поражением вышедшего и победой остальных. Партия завершается; оставшиеся могут начать новую. В пустом лобби ресурсы освобождаются, при выходе хозяина права переходят следующему игроку.
- При выходе участника или обрыве его соединения в чате появляется системное сообщение с его именем.
- Чат справа доступен в лобби, во время партии и после неё. Отправка — **Send** или Enter. Сообщения получают только участники этого лобби. Максимальная длина — 240 байт UTF-8.
- **Profile** в главном меню показывает победы и поражения. Кнопка **Close** закрывает окно профиля. Для аккаунтов статистика сохраняется в `stats.txt` рядом с запущенным сервером, для гостей — только до выхода из текущей сессии. Повторный вход в один аккаунт одновременно запрещён.

Колода содержит 52 карты, при старте раздаётся по шесть. Подкидывать можно карты достоинств на столе; максимум шесть атакующих карт за раунд и не больше, чем защитник может отбить. Отбой разрешён атакующему только после защиты всех карт. После взятия защитник пропускает ход.

## Проверки

```sh
make test
# Проверки памяти и неопределённого поведения:
make clean
make test SANITIZE='-fsanitize=address,undefined -fno-omit-frame-pointer'
# Регрессионные тесты состояния графического клиента:
make test-ui
```

Тесты сервера проверяют последнюю карту при непустой колоде, запрет неверных ходов, повторный старт, выход, смену хозяина, взятие карт. TCP-тесты проверяют чат, сохранение профиля после перезапуска, обрыв соединения, несколько команд в одном пакете и слишком длинные входные строки. Порт 5555 должен быть свободен.

## Протокол

Команды и ответы разделяются переводом строки. Основные команды после входа:

| Команда | Действие |
| --- | --- |
| `#list` | Список лобби, завершается `#list_end` |
| `#create NAME [PASSWORD]`, `#join ID [PASSWORD]` | Создать / войти в лобби |
| `#game_start`, `#restart` | Начать партию (только хозяин, от двух участников) |
| `#attack 6^ 6v` | Атака / подкидывание |
| `#defend 7^ 0` | Отбить карту в паре с индексом 0 |
| `#take`, `#pass` | Взять стол / завершить отбитый раунд |
| `#chat TEXT` | Сообщение участникам лобби |
| `#profile` | Имя, победы и поражения |
| `#leave` | Покинуть лобби, сохранив соединение |

`#list` передаёт пятое поле — признак защиты паролем (0/1), без самого пароля. `#password_required` / `#password_incorrect` запрашивают пароль или повтор ввода. `#deck CARD COUNT` передаёт точную козырную карту и размер колоды.

`#game_end ID` содержит **ID победителя**, а не проигравшего. Значения `-1` и `-2` обозначают поражение и победу из-за выхода участника соответственно. `#left` подтверждает выход; `#lobby COUNT` начинает обновление состава и индексов игроков.

## Ограничения

Существующий формат `userdata.txt` хранит пароли открытым текстом, а TCP-соединение не шифруется. Проект рассчитан на локальное / учебное использование; не используйте реальные пароли. Файлы аккаунтов и статистики исключены из Git.
